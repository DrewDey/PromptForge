Booking-Flow Handoff Simulator

Design, run, and audit your message automation before it goes live. Offline, self-contained, nothing leaves this page.

Flow Steps

Each step is a message your automation would send. Set when it fires, what it says, and any condition that must be true for it to fire.

Branch Variables

Define the variables a scenario can set (e.g. customer_type, deposit_required). Steps can require a specific value to fire.

Edge Cases

Toggle-able events that interrupt the normal flow. When active in a scenario, steps after the trigger point can be set to fire, skip, or replace.

Compliance Rules

Plain checks run against any generated transcript. Use these to catch "we forgot to send X" or "we sent something after a cancellation" before automating.

Handoff Receipt

A plain-text record of this run \u2014 useful to attach to a ticket or keep as a sign-off before you flip automation on.

Save / Load this flow

Export your flow + rules to a file you keep with this tool, or paste one back in to restore it. Nothing is stored automatically — save before you close the tab.
