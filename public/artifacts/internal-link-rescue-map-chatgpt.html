Internal Link Rescue Board

Paste pages, score orphan or underlinked risk, then generate source pages, target pages, anchor text, and a copyable rescue plan.

Accepted formats: pipe, tab, or CSV. Best fields are title, URL, topic, inlinks, outlinks. Inlinks can be blank if unknown.
This tool does not crawl your site. It uses pasted counts and page similarity to create a practical internal-link rescue plan.
