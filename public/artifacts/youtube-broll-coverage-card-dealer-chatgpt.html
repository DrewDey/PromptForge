YouTube B-roll Coverage Dealer

Turn a loose premise into scenes, claims, B-roll cards, coverage warnings, and a copyable shoot checklist.

1. Premise

Keep it rough. The board uses this to seed hook, texture, proof, and CTA shots.

2. Scenes and claims

Add the beats that need visual support. Claims with weak evidence will be flagged.

3. B-roll card dealer

Generate cards, then deal them into intro, body, proof, and CTA. You can edit every card.

4. Coverage check

Use this as the pickup warning system before filming or editing.

5. Slot board

Tap a card’s slot menu to move it. Use status to separate needed, shot, and skipped footage.

6. Shoot checklist

Copy this into notes before shooting or download it as a text file.
