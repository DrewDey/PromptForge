# Seed Idea Quality

Use this reference before generating a PathForge seed when the user has not provided a specific build idea.

## Product Direction

PathForge starts with obvious, desirable, low-friction builds. The site is mostly empty, so do not jump to huge enterprise workflows or obscure niche projects.

The target visitor is someone staring at an AI screen, bored or stuck, wondering what they can make tonight. A good seed makes them think, "I could try that."

## Simple Does Not Mean Lazy

Good first prompts are simple but well written:

- specific enough to produce a visible artifact,
- short enough to feel like something a normal user would type,
- concrete enough that the result can be verified,
- interesting enough to fork,
- not overloaded with every possible feature.

Avoid:

- giant feature lists,
- generic "make me an app" prompts,
- corporate-sounding workflows nobody wants to open for fun,
- projects where the artifact is only a wall of text,
- multi-step chains that look planned before the first output exists.

Do not use this reference as a phrase bank. It should help choose good ideas,
not make every first prompt start the same way. If several prompts in a batch
sound like one sentence with swapped nouns, rewrite them naturally without using
a new fixed opener list.

## First-Taste Standard

Every seed should pass at least three:

- The artifact is visible or usable in under 15 seconds.
- The prompt is easy to copy and try in another model.
- The result can be played, clicked, edited, calculated, exported, or inspected.
- The idea is broad enough that many users understand it.
- The artifact naturally suggests a fork.
- The output teaches what is possible with token maxing or a one-shot build.

## Game Seeds

Prefer self-contained browser games, fast toys, and remixable mechanics.

Strong starter ideas:

- Breakout with one twist.
- Tetris-like falling blocks with a theme.
- Flappy-style avoidance game.
- Minesweeper with a visual skin.
- Memory card game with generated icons.
- Wordle-style daily word puzzle.
- Snake fork with one original rule.
- Tiny tower defense lane game.
- Clicker or idle economy game.
- Reaction-time trainer.
- Typing speed challenge.
- One-screen physics sandbox.
- Micro racing game.
- Lemonade-stand sim.
- Puzzle box with three rooms.

## Productivity Seeds

Prefer practical one-file tools that save time, clarify choices, or turn messy thoughts into usable structure.

Strong starter ideas:

- Meeting cost calculator.
- Pomodoro timer with task notes.
- Habit tracker with local storage.
- Decision matrix.
- Budget splitter.
- Grocery list organizer.
- Workout set tracker.
- Invoice/quote generator.
- Daily plan builder.
- Email subject-line tester.
- Flashcard maker.
- Study timer with spaced review.
- Kanban board with local storage.
- Packing list generator.
- Resume bullet improver.
- Simple CRM follow-up tracker.

## Idea Selection Weights

For early seeding, split domains roughly:

- 50% games and playful experiments,
- 40% productivity/work tools,
- 10% other broad categories only when the idea is unusually strong.

Within each domain, favor obvious ideas over novelty until PathForge has enough baseline examples.

## Continuation Fit

If a seed continues past one prompt, the next prompt should sound like the user noticed something:

- "The controls work, but mobile is cramped..."
- "I forgot to ask for saved history..."
- "The calculator is useful, but the result needs an export button..."
- "The game works, but there is no reason to replay..."

Do not continue just to make the chain longer.
